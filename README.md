# Repositorio de Utensilios de Cocina

Este repositorio contiene la aplicación web estática para la gestión y control de la lista de utensilios de cocina.

## Publicar en GitHub Pages

1. Sube los archivos `index.html` y este `README.md` a la rama principal (`main` o `master`) de tu repositorio en GitHub.
2. Ve a la pestaña **Settings** (Configuración) de tu repositorio.
3. En la barra lateral izquierda, haz clic en **Pages**.
4. En **Build and deployment**, selecciona la rama `main` (o `master`) y la carpeta `/ (root)` como fuente (*Source*).
5. Haz clic en **Save**. ¡Listo! Tu página estará accesible en la URL que te proporcione GitHub Pages.
